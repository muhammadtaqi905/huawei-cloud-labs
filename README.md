# Huawei Cloud Labs

Welcome to my Huawei Cloud practical labs repository. Here you can find the documentation for different cloud services.

## List of Labs
* [Storage Lab](./Storage-Lab) - Elastic Volume Service (EVS), Object Storage (OBS), and Scalable File System (SFS).
* [Compute Lab](./Compute-Lab) - Elastic Cloud Server (ECS) and Virtual Private Cloud (VPC) setup.
* [Database Lab](./Database-Lab) - Relational Database Service (RDS), database configuration, backups, and connectivity.
